## 3. 模型建立 (Model Formulation)



为了解决多层复杂建筑内的紧急搜救问题，针对建筑内部空间尺度差异极大（如巨型仓库与狭小公寓共存）以及火灾烟雾导致的动态环境退化，我们建立了一个**基于分层混合图的时变多智能体协同规划模型 (Hierarchical Hybrid Graph-Grid Time-Dependent Model)**。该模型耦合了宏观拓扑导航、微观网格避障、动态烟雾扩散动力学以及基于空间分解的并行搜索策略。



### 3.1 模型假设 (Assumptions)



为使问题可解并符合代码仿真逻辑，作如下合理假设：

1. **分层空间假设**：建筑被抽象为“高层拓扑图”与“低层栅格图”的混合体。跨房间/楼层的宏观移动仅考虑拓扑连通性（必须经过门、楼梯），房间内部的微观搜索考虑详细障碍物与网格步长。
2. **异构烟雾扩散假设**：不同功能分区的耐烟能力不同。大空间（如仓库）的临界失效时间显著长于小空间（如公寓）。能见度随时间呈指数衰减，且直接制约救援人员的移动速度。
3. **能力同质性与状态独立性**：所有救援人员（Responders）具备相同的基准移动速度（直线、转弯、楼梯），但在烟雾中受到的速度惩罚取决于其实时所处位置的能见度。
4. **任务不可分与撤离约束**：除特定的大型区域（仓库）采用空间分解的并行搜索外，普通房间任务由单人完成。任务终点定义为所有目标被覆盖且全员安全撤离至出口。



### 3.2 三维异构空间分层建模 (3D Hierarchical Spatial Modeling)



我们将搜救场景建模为两层嵌套结构：全局加权图 $G$ 和局部网格 $M$。



#### 3.2.1 宏观拓扑层 (High-Level Topological Graph)



定义全局无向图 $G_{high} = (V, E)$，其中节点集合 $V$ 包含四类关键位置：



$$V = \{v_{entry}\} \cup \{v_{room}\} \cup \{v_{door}\} \cup \{v_{trans}\}$$

- **入口与出口 (Entries/Exits)**：外部救援切入点。
- **房间质心 (Room Centroids)**：各功能区（仓库、商铺、公寓）的逻辑中心。
- **连接点 (Doors/Connectors)**：连接房间与公共区域的关键瓶颈。
- **过渡点 (Transitions)**：楼梯口、走廊节点，负责 $Z$ 轴层间切换。

边集合 $E$ 代表节点间的连通性，其权重 $w_{ij}$ 为两点间的欧几里得距离（楼梯段包含垂直高度惩罚）。



#### 3.2.2 微观网格层 (Low-Level Grid Map)



对于复杂区域（如 Warehouse），我们引入分辨率为 $\delta$ (代码中 RESOLUTION=0.25m) 的二维栅格地图 $M_{grid}$：



$$M_{grid}(x,y) \in \{0, 1, 2\}$$



其中 0 代表可通行区域，1 代表墙壁边界，2 代表内部障碍物（Obs）。此层用于执行 A* 避障寻路和精细化扫描。



### 3.3 动态烟雾耦合与速度衰减机制 (Dynamic Smoke Coupling & Velocity Decay)



本模型的核心在于移动代价并非静态，而是随时间 $t$ 动态演变的函数。



#### 3.3.1 差异化能见度衰减



对于任意区域 $z_i$，定义其临界失效时间为 $T_{crit}^{(i)}$。该区域在 $t$ 时刻的有效视觉半径 $R_i(t)$ 遵循指数衰减规律：



$$R_{i}(t) = (R_{max} - R_{min}) \cdot e^{-\lambda_{i} t} + R_{min}$$



其中衰减系数 $\lambda_i$ 由区域的空间属性决定（代码逻辑）：



$$\lambda_{i} \approx \frac{3}{T_{crit}^{(i)}}$$

- **大空间 (Warehouse)**：$T_{crit} = 1800s$，衰减极慢。
- **小空间 (Apt/Shop)**：$T_{crit} = 360s$，衰减迅速。



#### 3.3.2 基于能见度的非线性速度映射



救援人员在 $t$ 时刻的移动速度 $v(t)$ 并非固定值，而是受当前区域能见度 $R(t)$ 的实时约束。根据仿真代码中的 `get_dynamic_speed` 函数，构建分段线性速度模型：

$$v(t) =  \begin{cases}  v_{base} & \text{if } R(t) \ge R_{thresh} \\ \max \left( v_{min}, v_{min} + (v_{base} - v_{min}) \cdot \frac{R(t) - R_{min}}{R_{thresh} - R_{min}} \right) & \text{if } R(t) < R_{thresh} \end{cases}$$

- $v_{base}$: 基准直线速度 ($1.2 m/s$)。
- $v_{min}$: 浓烟环境下的最低蠕行速度 ($0.2 m/s$)。
- $R_{thresh}$: 速度受影响的能见度阈值 ($2.0 m$)。

这意味着救援越滞后，在小房间内的移动代价 $Cost(t) = d / v(t)$ 将呈反比例急剧增加。



### 3.4 混合搜索策略与时间代价计算 (Hybrid Search Strategy)



针对不同类型的任务目标，模型采用差异化的时间代价计算方式：



#### 3.4.1 定点搜索 (Target Point Search)



对于已知坐标的目标（如 `Injured` 或 `Search Point`），总时间 $T_{task}$ 由两部分组成：

1. **宏观抵近**：在 $G_{high}$ 上使用 Dijkstra 算法计算从当前位置到目标所在区域“门节点”的最短路径时间。
2. **微观寻路**：在 $M_{grid}$ 上使用 A* 算法计算从“门”到具体坐标的避障路径时间。



#### 3.4.2 区域覆盖搜索 (Area Sweep)



对于未知具体位置的区域搜寻，策略取决于房间类型与当前能见度：

- **小型房间 (Apt/Shop)**：

  - 若 $R(t) > 2.5m$：执行**周界搜索 (Perimeter Search)**，沿墙壁行走一圈。
  - 若 $R(t) \le 2.5m$：执行**地毯式搜索 (Zigzag Search)**，路径长度显著增加。

- 大型复杂区域 (Warehouse Parallel Sweep)：

  这是本模型的创新点（对应代码 V11）。针对超大面积仓库，采用空间分解并行扫描策略：

  1. 将仓库栅格 $M_{wh}$ 沿 X 轴分割为 $N_{wh}$ 个子区域（Sub-zones）。
  2. 分配 $N_{wh}$ 名救援人员并行进入。
  3. 每名人员仅负责其子区域内的弓字形扫描（Zigzag），并自动跳过障碍物。

  单人扫描代价 $T_{sweep}$ 计算如下：

  

  $$T_{sweep} = \sum_{k=1}^{K} \frac{||p_{k+1} - p_k||}{v(t_{arrival} + \Delta t_k)} + T_{penalty}$$



### 3.5 全局优化目标 (Optimization Problem)



设救援人员集合 $A = \{1, ..., N\}$，任务集合 $J = \{1, ..., M\}$。决策变量为任务分配方案 $\Pi$ 和各队员的任务序列。

目标是最小化系统的**最大完工时间 (Makespan)**，即最后一名队员安全撤离的时间：

$$\min_{\Pi} \left( \max_{i \in A} C_i \right)$$

其中 $C_i$ 为队员 $i$ 的总耗时：



$$C_i = t_{start} + \sum_{j \in \pi_i} (T_{travel}^{(j)} + T_{action}^{(j)}) + T_{exit}$$



### 3.6 求解算法：动态贪婪分配 (Dynamic Greedy Allocation)



鉴于环境的时变特性，模型不进行预先的静态规划，而是采用**事件驱动的动态贪婪策略 (Event-Driven Dynamic Greedy Strategy)**，对应代码的主循环逻辑：

1. **初始化**：所有队员在 $t_{start}$ 时刻位于不同入口，状态为 `Free`。
2. **任务队列**：将任务按优先级排序（优先高危人员，其次扫楼，最后仓库扫描）。
3. **贪婪指派**：
   - 当任一队员 $i$ 完成当前任务变为空闲时，计算队列中队首任务 $j$ 分配给该队员的预计代价。
   - 选择当前全局最早空闲的队员（Min-Available-Time）执行下一个任务，以实现自动负载均衡。
   - 公式：$Res_{next} = \arg \min_{i} (TimeFree_i)$。
4. **状态更新**：每完成一个任务，更新该队员的累积时间 $TimeFree_i$，并基于新的绝对时间重新计算下一个房间的烟雾浓度 $R(t)$ 和移动速度 $v(t)$。
5. **终止与撤离**：任务队列清空后，规划所有队员从当前位置到最近出口的最短路径。
