1. # 3. 模型建立 (Model Formulation)

   

   为了解决多层建筑中随时间演变的紧急疏散搜救问题，特别是考虑到不同房间因体积差异导致的烟雾扩散速率非均匀性，我们建立了一个**异构环境下的时变多旅行商规划模型 (Heterogeneous Time-Dependent mTSP)**。该模型耦合了三维空间拓扑、差异化烟雾扩散动力学以及自适应搜救行为。

   

   ## 3.1 模型假设 (Assumptions)

   

   1. **拓扑连通性假设**：建筑被视为三维离散网络。不同楼层间的移动必须经过唯一的楼梯节点（Bottleneck），不允许穿墙或瞬移。
   2. **差异化烟雾扩散假设**：烟雾在不同房间内的积聚速率与其空间体积相关。大空间房间的烟雾充满时间显著长于小空间房间。能见度（有效视觉半径）随时间呈指数衰减。
   3. **自适应搜救假设**：
      - **动态策略**：搜救人员根据到达房间时刻的实时能见度，自动切换“沿墙巡视”或“地毯式搜索”模式。
      - **完备性约束**：任务完成的定义为所有房间被搜寻完毕，且所有队员撤离至一层安全出口。
   4. **能力同质性**：所有响应人员具备相同的移动速度基准，但在浓烟环境下移动速度会受限。

   

   ## 3.2 三维异构空间模型 (3D Heterogeneous Spatial Model)

   

   我们将搜救场景建模为一个加权图 $G=(V, E)$，其中节点集合 $V$ 包含具有不同物理属性的房间节点。

   

   ### 3.2.1 房间异构性建模

   

   设房间集合 $R = \{r_1, r_2, ..., r_M\}$。每个房间 $r_i$ 不仅具有几何属性（坐标、尺寸），还被赋予一个**风险衰减系数 $\lambda_i$**，以反映其受烟雾影响的快慢。

   根据流体力学原理及经验数据，我们将房间分为两类：

   - **大体积房间 (Large Rooms)**：如一层大厅或合并办公室。设定其临界失效时间 $T_{crit}^{L} = 10$ 分钟。
   - **小体积房间 (Small Rooms)**：如二层标准办公室。设定其临界失效时间 $T_{crit}^{S} = 6$ 分钟。

   

   ### 3.2.2 跨层移动代价

   

   定义任意两点 $A, B$ 之间的移动代价 $Cost(A, B)$。若涉及跨层（$z_A \neq z_B$），必须经过楼梯节点 $S$：

   

   $$T_{travel}(A, B) = \frac{\|A - S\|_2}{v_h} + \frac{H_{floor}}{v_v} + \frac{\|S - B\|_2}{v_h}$$

   

   其中 $H_{floor}=2.5m$ 为层高，$v_h, v_v$ 分别为水平和垂直移动速度。

   

   ## 3.3 差异化动态环境耦合 (Differential Dynamic Coupling)

   

   本模型的核心创新在于引入了**基于房间属性的差异化烟雾衰减机制**。

   

   ### 3.3.1 房间级视觉半径衰减

   

   设 $t$ 为绝对时间。对于房间 $r_i$，其内部有效视觉半径 $R_i(t)$ 遵循特定的指数衰减规律：

   

   $$R_i(t) = (R_{max} - R_{min}) \cdot e^{-\lambda_i t} + R_{min}$$

   其中衰减系数 $\lambda_i$ 由该房间的临界时间 $T_{crit}^{(i)}$ 决定：

   

   $$\lambda_i \approx \frac{3}{T_{crit}^{(i)}}$$

   

   这意味着小房间（$T_{crit}=360s, \lambda \approx 0.0083$）的能见度下降速度显著快于大房间（$T_{crit}=600s, \lambda = 0.005$）。

   

   ### 3.3.2 搜寻时间与能见度的非线性映射

   

   搜寻房间 $r_i$ 所需的时间 $T_{sweep}^{(i)}$ 是到达时刻 $t_{arr}$ 的函数。

   - 高能见度 ($R_i(t_{arr}) > 2.5m$)：采用周界搜索。

     

     $$T_{sweep} = \frac{2(L_i + W_i)}{v(t_{arr})}$$

   - 低能见度 ($R_i(t_{arr}) \le 2.5m$)：采用地毯式搜索。路径长度激增，且引入效率因子 $\eta=0.3$。

     

     $$T_{sweep} = \frac{Area_i / (\kappa \cdot R_i(t_{arr}))}{v(t_{arr}) \cdot \eta}$$

     

     此公式体现了“越晚到达小房间，代价呈指数级暴增”的惩罚机制。

   

   ## 3.4 全局优化模型 (Optimization Problem)

   

   

   ### 3.4.1 决策变量

   

   我们寻求最优的人员数量 $N$、任务分配方案 $\mathcal{A} = \{A_1, ..., A_N\}$ 以及每个队员的访问序列 $\pi_k$。

   

   ### 3.4.2 目标函数

   

   最小化系统的最大完工时间 (Makespan)：

   

   $$\min_{N, \mathcal{A}, \pi} \left( \max_{k=1...N} \left( t_{start} + \sum_{j \in \pi_k} (T_{travel} + T_{sweep}^{(j)}(t)) + T_{evac} \right) \right)$$

   

   ### 3.4.3 约束条件

   

   - **覆盖约束**：$\bigcup_{k=1}^N A_k = R$，所有房间必须被搜寻。
   - **时序约束**：第 $j+1$ 个任务的开始时间必须晚于第 $j$ 个任务的结束时间及路途时间。
   - **撤离约束**：所有队员最终位置必须位于一层安全出口。

   

   ## 3.5 求解算法：混合贪婪迭代搜索 (Hybrid Greedy-Iterative Search)

   

   针对该 NP-hard 问题，我们设计了以下求解流程：

   1. **外层循环（参数寻优）**：遍历响应人数 $N \in [1, 8]$，探究边际效益递减点。
   2. **内层循环（路径规划）**：
      - **蒙特卡洛采样**：随机生成房间优先权序列。
      - **贪婪负载均衡 (Min-Max Heuristic)**：在每一步分配任务时，计算将当前房间分配给每一位队员后的预计完工时间，选择增量最小（或当前最空闲）的队员，以实现自动负载均衡。
      - **状态更新**：实时更新队员位置及累计时间，重新计算下一个房间的烟雾状态 $R(t)$。
   3. **灵敏度分析**：通过调整 $t_{start}$（初始延迟），模拟不同火灾阶段介入对搜救策略的影响。
