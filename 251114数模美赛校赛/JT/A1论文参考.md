# 3. Mathematical Model





## 3.1 模型假设 (Assumptions)



为了简化复杂现实环境并构建可解的数学模型，我们提出以下假设：

1. **环境几何假设**：办公室被视为二维矩形平面，走廊连接所有房间。房间内的障碍物忽略不计，但考虑到必须搜寻“死角”，模型强制搜救路径必须覆盖房间的四个角落。
2. **烟雾扩散假设**：烟雾浓度随时间单调递增，导致能见度（有效视觉半径）呈指数衰减。假设所有房间的烟雾扩散规律一致。
3. **搜救者行为假设**：搜救人员（Responders）严格遵守安全协议。在能见度高时，采用沿墙巡视（Perimeter Search）；在能见度低时，采用地毯式弓形搜索（Zigzag Search）。
4. **速度受限假设**：搜救人员的移动速度不是恒定的，而是受当前能见度影响。能见度越低，移动越谨慎（速度越慢）。



## 3.2 符号说明 (Notations)



- $t$ : 自火灾发生起的绝对时间 (s)。
- $t_{delay}$ : 搜救人员进入现场的延迟时间 (Start Delay)。
- $R(t)$ : $t$ 时刻搜救人员的有效视觉半径 (m)。
- $v(R)$ : 基于当前视场半径的移动速度 (m/s)。
- $\eta$ : 低能见度下的搜索效率系数 (Efficiency Factor, $\eta \in (0, 1]$)，用于模拟重复确认和清除障碍的时间损耗。
- $\mathcal{S}$ : 房间集合 $\{1, 2, ..., 6\}$。
- $P_{path}$ : 单个房间内的搜寻路径长度 (m)。



## 3.3 动态环境模型 (Dynamic Environmental Model)





### 3.3.1 视觉半径衰减模型



我们引入指数衰减函数来描述烟雾对视觉的影响。设 $R_{max}$ 为房间对角线长度（理想视场），$R_{min}$ 为极限视场（如触觉搜索范围 0.5m）。视场半径 $R(t)$ 定义为：

$$R(t) = (R_{max} - R_{min}) \cdot e^{-\lambda t} + R_{min}$$

其中 $\lambda$ 为衰减系数，由临界时间 $T_{crit}$ 决定（即能见度降至最低所需的时间）。



### 3.3.2 速度与效率耦合模型



搜救人员的移动速度 $v(t)$ 是视场半径 $R(t)$ 的分段函数。当能见度低于安全阈值（设为 2.0m）时，速度开始线性下降：

$$v(t) =  \begin{cases}  v_{base}, & R(t) \ge 2.0 \\ v_{min} + (v_{base} - v_{min}) \cdot \frac{R(t) - R_{min}}{2.0 - R_{min}}, & R_{min} \le R(t) < 2.0  \end{cases}$$

此外，在计算低能见度下的搜寻时间时，引入效率因子 $\eta = 0.3$，此时有效搜寻速度为 $v_{eff} = v(t) \cdot \eta$。这反映了在浓烟中搜救人员需要反复扫视、蹲伏或清理障碍的真实情况。



## 3.4 自适应路径生成算法 (Adaptive Path Generation)



为了计算搜寻单个房间 $i$ 所需的时间 $T_{sweep}^{(i)}$，我们根据救援人员到达该房间时刻 $t_{arr}$ 的视场半径 $R(t_{arr})$，动态生成两种拓扑路径：



### 3.4.1 模式 A：高能见度周界搜索 (Perimeter Search)



当 $R(t_{arr}) > R_{thresh}$ (设为 2.5m) 时，视为清晰环境。

- **策略**：搜救人员从门口出发，前往最近的角落，依次遍历四个角落，最后返回门口。
- **路径长度** $L_{peri}$：近似等于房间周长加上进出门的距离。
- **耗时**：$T_{sweep}^{(i)} = L_{peri} / v(t_{arr})$。



### 3.4.2 模式 B：低能见度地毯式搜索 (Zigzag Search)



当 $R(t_{arr}) \le R_{thresh}$ 时，视为烟雾环境。

- **策略**：采用弓字形（Zigzag）路径覆盖全屋。

- 扫描密度：扫描线的间距（Step Size）$\delta$ 动态取决于当前视场：

  

  $$\delta = \max(\delta_{min}, \kappa \cdot R(t_{arr}))$$

  

  其中 $\kappa$ 为重叠系数。$R(t)$ 越小，$\delta$ 越小，路径越密集。

- **路径长度** $L_{zigzag}$：随烟雾浓度增加而显著增加。

- 耗时：考虑到低能见度下的效率折损：

  

  $$T_{sweep}^{(i)} = \frac{L_{zigzag}}{v(t_{arr}) \cdot \eta}$$

此模型捕捉了**“越晚进入房间，搜寻代价呈非线性急剧增加”**的关键特征。



## 3.5 全局优化求解 (Global Optimization)





### 3.5.1 问题定义



这是一个带有时间依赖代价的多旅行商问题 (Time-Dependent mTSP)。我们需要确定两个决策变量：

1. **任务分配 (Partitioning)**：将房间集合 $\mathcal{S}$ 划分为两个子集 $S_1$ 和 $S_2$，分别分配给两名搜救人员。
2. **访问顺序 (Permutation)**：确定每个子集内的访问序列 $\pi_1, \pi_2$。



### 3.5.2 目标函数



系统的总耗时取决于最后一名搜救人员完成并撤离的时间（木桶效应）。

设 $T_{k}$ 为第 $k$ 名搜救人员完成任务的总时间，其计算是一个递归过程。对于路径序列 $\pi_k = \{r_1, r_2, ..., r_m\}$：

$$t_{arr, j} = t_{start} + \sum_{p=1}^{j-1} (T_{travel}^{(p)} + T_{sweep}^{(p)}) + T_{travel}^{(j)}$$

$$T_{k} = t_{arr, m} + T_{sweep}^{(m)} + T_{evac}$$

其中 $t_{start} = t_{delay}$。我们的优化目标是最小化系统的最大完工时间 (Makespan)：

$$\min_{\pi_1, \pi_2} \left( \max(T_1, T_2) \right)$$



### 3.5.3 求解算法



考虑到房间数量较少 ($N=6$)，我们采用**全空间搜索算法 (Exhaustive Search)**：

1. 遍历所有可能的房间分配方案（打破 3:3 平均分配的限制，允许 2:4 或 1:5）。
2. 对每一种分配，遍历所有可能的房间访问顺序及进出口组合。
3. 模拟每条路径的时间累积过程，计算目标函数值。
4. 输出 $MakeSpan$ 最小的策略作为最优解。
