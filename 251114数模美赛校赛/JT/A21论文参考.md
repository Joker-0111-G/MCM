# 3. 模型建立 (Model Formulation)



针对具有双侧疏散通道的多层建筑搜救问题，我们建立了一个**基于拓扑图论的时变多旅行商规划模型 (Graph-based Time-Dependent mTSP)**。该模型特别考虑了多路径选择（双楼梯）对跨层移动效率的优化作用，以及随时间恶化的火灾环境对搜救效能的非线性影响。



## 3.1 模型假设 (Assumptions)



1. **空间拓扑假设**：建筑被抽象为三维离散网络。每一层为二维平面，层间通过位于走廊两端的两个楼梯节点（Bottlenecks）连接。人员只能通过楼梯进行垂直移动。
2. **烟雾扩散假设**：烟雾浓度随时间单调递增，导致能见度（有效视觉半径）呈指数衰减。
3. **智能决策假设**：
   - **路径寻优**：搜救人员在需要跨层移动时，能够根据当前位置实时计算并选择距离目标最近的楼梯（左侧或右侧）。
   - **动态搜寻**：根据到达房间时刻的能见度，自动切换“沿墙快速巡视”或“地毯式搜索”模式。
4. **能力同质性**：所有响应人员（Responders）具备相同的移动速度基准，但在浓烟环境下移动速度会受限。



## 3.2 三维空间拓扑模型 (3D Spatial Topology)



我们将搜救场景建模为一个加权图 $G=(V, E)$。



### 3.2.1 节点定义



集合 $V$ 包含三类关键节点：

- **目标节点 (Rooms)**：$R = \{r_1, r_2, ..., r_M\}$，每个房间 $r_i$ 具有属性 $(x_i, y_i, z_i)$。
- **连接节点 (Stairs)**：$S = \{S_L, S_R\}$，分别代表左侧楼梯（$x=0$）和右侧楼梯（$x=18$）。每个楼梯在每层都有对应的出入口坐标。
- **出入口节点 (Exits)**：$E_{start} \subset V$，表示一层走廊两端的初始位置。



### 3.2.2 智能跨层路径代价 (Intelligent Cross-Floor Cost)



定义任意两点 $A, B$ 之间的移动代价 $Cost(A, B)$。

- 同层移动 ($z_A = z_B$)：

  

  $$T_{travel} = \frac{\|A - B\|_2}{v_h}$$

- 跨层移动 ($z_A \neq z_B$)：由于存在两个楼梯，移动路径需通过优化决策选择。

  设 $S_L$ 为左楼梯路径，$S_R$ 为右楼梯路径。路径总距离分别为：

  

  $$D_L = \|A - S_L^{(A)}\|_2 + H_{floor} + \|S_L^{(B)} - B\|_2$$

  $$D_R = \|A - S_R^{(A)}\|_2 + H_{floor} + \|S_R^{(B)} - B\|_2$$

  

  搜救人员选择距离最短的路径：

  

  $$T_{travel} = \frac{\min(D_L, D_R)}{v_{avg}}$$

  

  其中 $v_{avg}$ 综合了水平速度 $v_h$ 和垂直速度 $v_v$。这一逻辑在代码的 simulate_step 函数中通过比较 dist_A 和 dist_B 实现。



## 3.3 动态环境耦合模型 (Dynamic Environment Coupling)





### 3.3.1 视觉半径衰减



设 $t$ 为绝对时间，$R(t)$ 为有效视觉半径：



$$R(t) = (R_{max} - R_{min}) \cdot e^{-\lambda t} + R_{min}$$



其中衰减系数 $\lambda$ 由临界时间 $T_{crit}=6 \text{ min}$ 决定。随着时间推移，$R(t)$ 迅速减小，迫使搜救人员改变搜索策略。



### 3.3.2 状态依赖的搜寻时间



搜寻房间 $i$ 的耗时 $T_{sweep}^{(i)}$ 是到达时刻 $t_{arr}$ 的分段函数：

1. **高能见度 ($R(t_{arr}) > 2.5m$)**：采用周界搜索（Perimeter Search）。路径长度 $L \approx 2(W+H)$。

2. 低能见度 ($R(t_{arr}) \le 2.5m$)：采用地毯式搜索（Zigzag Search）。扫描线间距 $\delta \propto R(t_{arr})$，路径长度随能见度降低呈反比急剧增加。

   此外，引入效率因子 $\eta=0.3$，模拟浓烟中摸索前进的时间损耗：

   

   $$T_{sweep} = \frac{L_{zigzag}(t_{arr})}{v(t_{arr}) \cdot \eta}$$



## 3.4 全局优化模型 (Optimization Problem)





### 3.4.1 决策变量



- **人员数量**：$N \in [N_{min}, N_{max}]$。
- **任务分配与顺序**：每个搜救人员 $k$ 的访问房间序列 $\pi_k$。



### 3.4.2 目标函数



最小化系统的最大完工时间 (Makespan)，即最后一名队员撤离至一层安全出口的时间：



$$\min_{N, \pi} \left( \max_{k=1...N} T_{total}^{(k)} \right)$$

其中第 $k$ 名队员的总时间包括：



$$T_{total}^{(k)} = t_{delay} + \sum_{j \in \pi_k} \left( T_{travel}^{(j)} + T_{sweep}^{(j)}(t_{arr}^{(j)}) \right) + T_{evac}^{(k)}$$

- $T_{evac}^{(k)}$：完成最后一个任务后，选择最近的楼梯下至一层并到达出口的时间。



## 3.5 求解算法：多重随机贪婪搜索 (Multi-Start Greedy Search)



鉴于问题规模较小（房间数 $M=6$），但包含复杂的非线性时间约束，我们采用了**暴力全排列 (Brute Force Permutation) 结合贪婪分配**的策略，以确保找到全局最优解：

1. **全排列生成**：生成所有可能的房间访问顺序 $\Pi$ ($M!$ 种)。

2. 内层循环（贪婪分配）：

   对于每一种顺序 $\pi \in \Pi$：

   - 按顺序取出房间任务。
   - 计算将该任务分配给每一位队员后的预计完工时间（考虑各自当前位置、跨层最优楼梯选择）。
   - **决策**：将任务分配给**增量成本最小**的队员。

3. **初始位置优化**：由于初始位置（左入口或右入口）影响结果，算法对每种排列进行多次随机初始位置采样，取最优值。

4. **灵敏度分析**：遍历 $N=1$ 至 $N=4$，输出不同人数下的最短时间，以确定最佳人员配置。

### 此部分在论文中的亮点 (Key Highlights)



1. **双通道优化 (Dual-Channel Optimization)**：模型显式地利用了“双楼梯”结构。通过计算并选择最优跨层路径，显著减少了无效的走廊往返移动，这在多层建筑搜救中是提高效率的关键。
2. **动态惩罚机制 (Dynamic Penalty)**：模型不仅计算了物理距离，还通过 $R(t)$ 和 $\eta$ 将时间流逝转化为搜救成本的指数级增加，真实反映了“早进场”的重要性。
3. **闭环验证**：模型包含了从“进入”到“搜寻”再到“撤离”的全过程，确保了搜救任务的完整性。
