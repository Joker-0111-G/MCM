## ⭐ 重点：2026 MCM/ICM 美赛（H 奖）

### 关于美赛

> MCM (Mathematical Contest in Modeling) / ICM (Interdisciplinary Contest in Modeling) 由美国数学及其应用联合会（COMAP）主办，是**全球最具影响力的数学建模竞赛**，每年吸引来自中国、美国、加拿大、英国等 20 多个国家的超过 20,000 支队伍参赛。

### 奖项等级

```
Outstanding Winner      (特等奖)     ≈ 前 1%
Finalist                (特等奖提名)  ≈ 前 5%
Meritorious Winner      (一等奖)     ≈ 前 10%
Honorable Mention       (二等奖)     ≈ 前 18% ~ 22%   ← 🏅 我们
Successful Participant  (成功参赛奖)  ≈ 全部参赛队
Unsuccessful            (不成功参赛)  ≈ 极少
```

| 工具                 | 用途                         | 占比  |
| :------------------- | :--------------------------- | :---: |
| **Jupyter Notebook** | 数据探索、建模验证、过程记录 | ≈ 60% |


## 💭 参赛心得

一路下来的几点真实感受：

**关于组队：**

> 三次比赛都是同一个核心团队，磨合成本低、配合默契。组队比选模型更重要。

**关于论文：**

> 美赛评奖首轮快速浏览摘要和摘要页。H 奖论文的摘要至少改了 5 遍——改到每个词都不多余。

**关于可视化：**

> 一张好图胜过三段文字。建模过程可以不完美，但论文一定要好看。

**关于工具：**

> 不一定要用最新算法。90% 的建模问题可以用经典方法 + 合理的改进来解决。算法创新不是必要的，**模型的合理性 + 清晰的逻辑**才是核心。

**关于时间：**

> 四天四夜合起来睡不到 15 个小时。最后一晚通宵改摘要，凌晨提交后整个人瘫在椅子上。但收到 H 奖邮件那一刻，一切都值了。

**关于 AI：**

> 2025 年起美赛允许使用 AI，我们的 Gemini 文档目录就是使用过程的完整记录。工具在进步，但**建模思维和团队协作能力**始终是核心竞争力。
